# Scope & Safe Harbor:
# We welcome reports from security researchers and developers.
# In-scope:
# - apps/api (REST API endpoints & authentication checks)
# - apps/web (Public storefront & documentation)
# - apps/dashboard (Control panel access controls & permission boundaries)
# - Container isolation & multi-tenant security
#
# Out-of-scope / Prohibited:
# - Denial of Service (DoS / DDoS) attacks
# - Automated high-volume spamming
# - Social engineering or phishing of employees or customers
# - Physical security attacks against server facilities
# - Degrading platform service availability or exfiltrating private customer data
#
# Please provide reproducible proof-of-concept steps. We aim to acknowledge reports within 24-48 hours.
